# Phonon runs as a local Python sidecar over the streaming WebSocket

Speech recognition uses the Phonon model from Fermion Research, served by a local `fermion serve phonon-2` process that the app starts and supervises; the app streams microphone audio to the server's `/v1/audio/stream` WebSocket and receives a whole-hypothesis partial roughly every 0.5 s and a final segment after each pause. Chosen over the native phonon-coreml Swift package because only the sidecar offers live partial transcription, which sentence tracking depends on, and because changing models becomes a command-line change (`phonon-2.5-en`, other Phonon variants, future engines). Cost: a Python 3.10+ runtime and the `fermion-research` package must be present, and the app owns the sidecar's lifecycle.
